# ACM SQL Learning Portal

## Overview

ACM SQL Learning Portal is a learning management platform developed for ACM student members to learn SQL in a structured and interactive way.

The platform provides topic-wise SQL learning resources, curated video lectures, quizzes, and personalized progress tracking. Students can learn at their own pace while administrators can easily manage content and monitor student engagement.

---

## Features

### Student Portal

#### Authentication

* Student Registration and Login
* Secure JWT Authentication
* Protected Dashboard Access

#### SQL Learning Resources

* Topic-wise SQL Roadmap
* Embedded YouTube Videos
* SQL Notes and Study Materials
* Structured Learning Path

#### Quiz System

* Topic-wise SQL Quizzes
* Multiple Choice Questions
* Instant Score Calculation
* Quiz History Tracking

#### Student Dashboard

Students can track:

* Topics Completed
* Videos Accessed
* Quizzes Attempted
* Average Quiz Score
* Progress Percentage
* Learning Activity

---

### Admin Portal

#### Content Management

Admin can:

* Add/Edit/Delete SQL Topics
* Upload YouTube Video Resources
* Add SQL Notes
* Organize Content Topic-wise

#### Quiz Management

Admin can:

* Create SQL Quizzes
* Add/Edit/Delete Questions
* Manage Quiz Content

#### Analytics Dashboard

Admin can monitor:

* Total Registered Students
* Student Enrollment Statistics
* Quiz Attempts
* Topic Completion Rates
* Student Performance Metrics
